# خدمة طباعة برندة المحلية

هذه الخدمة اختيار الطباعة المباشرة على جهاز الكاشير بنظام ويندوز وتعمل دون الإنترنت بعد تجهيزها مرة واحدة
المتصفح وحده يفتح نافذة الطباعة ولا يستطيع اختيار طابعتين والطباعة الصامتة تلقائيًا

## التجهيز مرة واحدة على جهاز الكاشير

1. ثبّت تعريف طابعة العميل وطابعة المطبخ في ويندوز ويمكن استخدام الطابعة نفسها
2. اضبط عرض الورق الحراري والقص في تفضيلات تعريف كل طابعة
3. وفّر إصدار نود ٢٤ ثم افتح هذا المجلد بعد توفير البرنامج على الجهاز ونفّذ التثبيت مرة واحدة بوجود الإنترنت

```powershell
npm install
npm run setup
npm start -- --origin=http://localhost:3100
```

استبدل العنوان بعنوان برندة الفعلي دون مسار أو شرطة أخيرة عند استخدام الموقع المنشور
الخدمة تقبل عنوانًا واحدًا بالضبط ويجب تطابق المنفذ أيضًا

4. انسخ رمز الربط من رسالة الخدمة ثم افتح المالية ← إعداد الطابعة في المتصفح نفسه وعلى الجهاز نفسه
5. اختر الطباعة التلقائية المباشرة وأدخل الرمز واضغط ربط وعرض الطابعات
6. حدد الطابعتين وعرض الورق ثم احفظ الإعدادات
7. شغّل الخدمة أثناء العمل وبالإمكان تشغيلها لاحقًا بالأمر التالي دون الإنترنت

```powershell
npm start
```

لا يغيّر هذا المشروع طابعة ويندوز الافتراضية ولا يضيف خدمة أو تشغيلًا تلقائيًا للنظام
إن ظهر طلب سماح بالوصول للشبكة المحلية من المتصفح اسمح للخدمة المحلية فقط
تهيئة البرنامج عند بدء تشغيل ويندوز وتغليفه كبرنامج مثبت خطوة توزيع منفصلة

## التشغيل وحالة الطباعة

- الإعدادات تخص العلامة والمتصفح والجهاز وتبقى في تخزين المتصفح
- اختيار الطابعة من الطابعات المثبتة فقط ولا تقبل الخدمة عناوين شبكية أو أوامر نظام للطباعة
- الإيصال يرسل بطلب ثابت لكل عملية ونسخة لمنع إعادة الطباعة عند تكرار الطلب أو إعادة تشغيل الخدمة
- تحفظ الخدمة بصمة الطلب وحالته فقط دون محتوى الفاتورة أو بيانات العميل
- نجاح الإرسال يعني قبول برنامج تشغيل الطابعة ولا يثبت خروج الورق فعليًا
- إذا انقطع الإرسال بعد بدء الطباعة تبقى الحالة غير مؤكدة ولا تعاد تلقائيًا افحص الطابعة ثم استخدم إعادة الطباعة اليدوية عند الحاجة
- اختيار عرض الورق في الواجهة يحدد تنسيق الإيصال ويجب أن يطابق عرض الورق في تعريف الطابعة
- خط تجوال العربي مضمّن داخل الخدمة مع رخصته وتعمل الصور المضمنة دون إنترنت أما الروابط الخارجية فتحجب
- عند تغيير عنوان الموقع أو إعادة الربط استخدم الخيار نفسه بعنوان جديد لتدوير رمز الربط ثم احفظه من جديد في الواجهة

## حدود التحقق

اختبارات الخدمة تتحقق من العزل والربط والطابعات المسموحة ومنع التكرار واستعادة الحالة بعد إعادة التشغيل
اختبار تشغيل محلي مخفي تحقق من تعداد طابعات ويندوز والاتصال بالخدمة وإنشاء ملف معاينة بالعربية مع الخط العادي والعريض مضمنين دون طباعة فعلية
لم توجد طابعة حرارية مثبتة على جهاز التطوير ويلزم اختبار الطابعة الحقيقية وتخطيط الورق على جهاز الكاشير بعد التجهيز

```powershell
npm test
npm run test:native
```
