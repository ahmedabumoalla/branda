# تبسيط إنشاء حساب جديد

البريد الإلكتروني اختياري في الواجهة والخادم، ويجري التحقق من صيغته عند إدخاله، وأزيل قسم موقع الفرع الرئيسي من صفحة التسجيل بالكامل

تُحفظ القيم الغائبة كقيم فارغة في قاعدة البيانات دون عناوين بديلة أو رابط موقع وهمي، ويستمر التحقق برقم واتساب وكلمة المرور وحماية محاولات التسجيل كما هو

أكد الفحص للقراءة فقط أن أعمدة البريد والموقع تقبل القيم الغائبة وأن دالة إنشاء الحساب المنشورة تطابق الدالة المختبرة، ولم يلزم تعديل قاعدة البيانات

نجح ٤١ فحصًا معزولًا للواجهة والخادم و٦٣ فحصًا محليًا على PostgreSQL، وتشمل إنشاء حسابين مختلفين دون بريد أو موقع والتحقق من عدم تعارضهما، دون إنشاء حسابات حقيقية أو إرسال رسائل
