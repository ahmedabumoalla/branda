# إعادة تصميم الرئيسية وعرض علامات العملاء

## تحديث شريط الشعارات

طلب المستخدم لاحقًا استبدال شبكة الشعارات بشريط متحرك، وهذا الطلب يحل محل اختيار العرض الثابت أدناه

أصبح العرض صفًا أفقيًا متصلًا يعيد الشعارات نفسها دون إضافة علامات أو تغيير شرط الاشتراك، مع زر إيقاف وتشغيل وتوقف عند التركيز أو مرور المؤشر

عند تفضيل تقليل الحركة تُوقف الحركة وتُخفى النسخة المكررة ويتاح التمرير اليدوي، والنسخة المكررة مخفية عن قارئات الشاشة

نجح اختبار الإيقاف والتشغيل والعرض والحفظ الأصلي وفحص الأنواع وسلامة النصوص، وسيُسجل تأكيد النشر بعد اكتماله

طلب المستخدم تغيير تكوين الرئيسية بسبب اعتراض طرف آخر على التشابه، وطلب نشر التصميم بعد الفحص

## التصميم

الاتجاه مبني على رحلة تشغيل النشاط: البيع ثم إدارة المخزون والعمل ثم الولاء، بمقدمة داكنة ونص ثابت ومسار عمل واضح، بدل لوحة الأرقام التوضيحية والجوال والتنبيهات العائمة والكلمات المتحركة

تستخدم الصفحة ألوان برنده البنية والذهبية، مع مساحة خضراء هادئة لشرح الأدوات، وخط آي بي إم العربي الموجود دون إضافة خطوط أو مكتبات

```text
Header / account / language
Business headline + connected workflow
Interactive workflow choices + detail panel
Static customer logo grid
Operations overview
Existing live plans and pricing
FAQ
Existing contact submission + footer

Brand #713e2b / Dark #342820 / Gold #ecc777
Paper #ffffff / Mint #edf3ed / Text #292722
```

- استبدلت واجهة الرئيسية بالكامل مع إبقاء الباقات الفعلية ومصدر الأسعار وتسجيل الدخول ونموذج التواصل وسلوكه الأصلي
- أزيلت من العرض شعارات القائمة المرجعية القديمة وعدد العملاء غير الموثق وادعاء التواصل خلال خمس دقائق
- قسم العلامات ثابت، بلا تمرير تلقائي أو أسماء مكتوبة تحت الشعارات، مع نص بديل للصور لسهولة الوصول
- القائمة التي طلبها المستخدم تضم ديلي كيك ولوكو وفواصل والكواكب وكاث وتوقذر بلانت وشاهي وهيل ومقص ٧٧
- كشف الفحص أن ديلي كيك ولوكو وفواصل مسجلة كتجريبية، وأُرسل سؤال توضيحي للمستخدم عن التعارض مع طلبه استبعاد التجريبي
- لحين تغيير هذا الشرط يعرض القسم فقط العلامات الخمس ذات الاشتراك الحالي النشط غير التجريبي، ولا يتم تعديل اشتراك أي علامة
- التحقق يجري على الخادم باستعلام واحد محدود بالقائمة المختارة، ويستبعد الحسابات غير العامة والمحذوفة والباقات المجانية وغير النشطة والاشتراكات المستقبلية والمنتهية والتجريبية
- لا تُرسل بيانات الاشتراك أو أسعاره أو بيانات العملاء للواجهة، فقط رموز العلامات المؤهلة
- عند تعذر التحقق يُخفى القسم بدل عرض بيانات غير مؤكدة

## الفحص

نجح فحص الأنواع الكامل واختبار عرض الشعارات دون عناوين والتفاعل مع الأقسام واللغة وحالات تسجيل الدخول والأسعار وإخفاء القسم عند غياب العلامات

نجح تحميل الرئيسية محليًا واسترجاع شعارات العلامات الخمس بصور صحيحة، دون فتح المتصفح أو إرسال نموذج تواصل أو أي رسائل
