## حالة هذه الجولة

النشر المجمع مأذون من المستخدم بعد تحسين الأداء والفحص


نسخة الإصدار المعزولة مبنية على فرع الإنتاج وتحفظ إصلاحاته بجانب التعديلات المحلية، دون إعادة ضبط مساحة العمل المشتركة
