# تحديث الفروع والديم وواحد معصوب — ١٧ نوفمبر ٢٠٢٦

أذن المستخدم بنشر التحديثات المكتملة على قيت هوب وفيرسال وتحديث التسليم
الحالة الحالية: دمج الإصدار وفحوص المصدر مكتملة ويجري التحقق من النشر

## نطاق التحديث

- إضافة الفروع وتعديل بياناتها وإحداثياتها لكل علامة يظهر لها خيار الفروع
- إدارة منيو مستقل لكل فرع أو اعتماد المنيو الأساسي مباشرة مع حفظ الأصناف المستقلة لاستعادتها
- ربط مواقع الفروع النشطة ببطاقات الولاء مع استبعاد المحذوف والموقوف ومنع رجوع الموقع القديم بعد مسحه
- تدعم المحفظة حتى عشرة مواقع مختلفة والتنبيه يعتمد على حفظ العميل للبطاقة وأذونات جهازه
- تحديثات الديم المكتملة للفواتير والمشتريات والكاشير والعملاء والولاء وبطاقات الأصناف والنظرة العامة
- فصل تجهيز طلبات المعمل عن تصنيع المصنع مع الجودة والتقارير وتتبع الباتشات
- هوية واحد معصوب ومنيوه وبطاقته وخيار ربط رقمه الخاص وإظهار مصدر إرسال الواتساب في إدارة العلامات
- الحفاظ على إصلاحات الإنتاج الأحدث لصلاحيات موظفي لوكو وإشعارات الاستبدال ومايند ونقوة والمتاجر

## التحقق

نجح فحص الأنواع للنسخة المجمعة واختبارات مصدر المنيو والواجهة ومواقع الولاء وتوقيع بطاقات آبل المحلي ومحاكاة جوجل
ترحيل الفروع طُبق بعد اختبار محلي من ٢٥ حالة وتجربة تجميع حية داخل معاملة متراجعة
تحقق التطابق مع سجل قاعدة البيانات لجميع ترحيلات الإصدار الثلاثة والعشرين
لم تُرسل رسائل اختبار حقيقية ولم تُحفظ فروع أو فواتير تجريبية في الإنتاج
لم يُجر فحص متصفح أو تأكيد إشعار على جهاز عميل
