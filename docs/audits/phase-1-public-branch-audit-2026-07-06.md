- النطاق: الصفحة الرئيسية والفرع الإلكتروني العام فقط.

## بيئة التشغيل

تمت محاولة تشغيل الخادم عبر الأمر الافتراضي:

```text
npm run dev
```

ثم تم تشغيله صراحة على منفذ مستقل باستخدام Turbopack:

```text
npx next dev --turbopack --port 3002
```

ثم تم تشغيله كمسار تدقيق بديل باستخدام Webpack:

```text
npx next dev --webpack --port 3003
```

حالة الخادم:

- خادم Turbopack بدأ بنجاح ثم خرج لاحقا بخطأ ذاكرة.
- خادم Webpack بدأ بنجاح، ثم سجل أخطاء ذاكرة وتعليق في طلبات لاحقة.
- الخادم اشتغل فعليا، لكنه لم يكن مستقرا بما يكفي لإكمال اختبار Phase 1 التفاعلي.
